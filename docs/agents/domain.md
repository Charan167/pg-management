# Domain Documentation

This is a single-context repository.

- `CONTEXT.md` is the authoritative glossary for domain language. Keep definitions concise and implementation-free.
- `docs/adr/` contains accepted decisions that are hard to reverse, surprising without context, and based on real trade-offs.
- Read `CONTEXT.md` before proposing new domain terms or changing existing relationships.
- Update the glossary when a term is resolved during domain modeling.
- Do not use `CONTEXT.md` as a product specification, implementation plan, or database schema.
